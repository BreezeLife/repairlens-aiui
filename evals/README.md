# RepairLens evaluation notes

The first evaluation fixture is intentionally narrow: an HVAC condenser whose fan stops after startup. Expand only after the end-to-end glasses workflow is stable.

Track:

- plan schema validity;
- presence of risk and evidence;
- confirmation required before every step transition;
- offline fallback behavior;
- response latency on the target Nebius endpoint;
- physical device input success for voice, Enter, and GlobalHook.
